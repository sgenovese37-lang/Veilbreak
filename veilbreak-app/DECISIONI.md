# Decisioni di design

Risposte alle domande del documento «Cosa manca per il gioco completo» (24 novembre 2026).

| Tema | Decisione | Note per lo sviluppo |
| --- | --- | --- |
| Creature in campo | Massimo **7** per giocatore | Le carte che evocano non hanno effetto se il campo è pieno; il controllo di una creatura nemica (Sindaco, Ultima Legge) va gestito quando il campo è pieno. |
| Chi gioca per secondo | **Una carta in più** nella mano iniziale e **1 Frammento di Essenza** | Il Frammento è una carta da 0 Essenza: +1 Essenza in questo turno, poi scompare. Serve un’illustrazione (ChatGPT). |
| Mazzi | **30 carte** | Con 15 carte per fazione: **3 copie** per le non leggendarie, **1** per le Leggendarie (vedi sotto). |

| Illustrazioni nuove | Create con **ChatGPT** | Per le lingue conviene chiedere anche versioni senza testo (vedi sotto). |
| Musica | **Generata, a tema VEILBREAK** | La compone il gioco stesso con Web Audio: un tema per il menu e uno per ogni ambientazione, originali. |
| Play Store | **Se ne parla a gioco finito** | |
| Gioco online | In valutazione: dipende dai costi | Stima dei costi nella risposta del 24 novembre. |
| Lingue | **Italiano, inglese, tedesco, spagnolo** | Interfaccia e testi delle carte in un file per lingua; le illustrazioni restano in italiano (vedi sotto). |

## Decise il 24 novembre

1. **Mazzi da 30 carte: opzione A.** Fino all’arrivo di nuove carte sono ammesse **3 copie** delle carte non leggendarie; le Leggendarie restano a **1**. Quando arriveranno carte neutrali o il secondo set si torna a valutare il limite.
2. **Lingue: illustrazioni in italiano.** Le immagini delle carte restano in italiano; si traducono interfaccia, regole delle carte, anteprima a dito premuto e scheda della carta (italiano, inglese, tedesco, spagnolo).
